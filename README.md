# HyperHealth Connect

Stato: baseline documentale enterprise 1.0.  
Ultimo aggiornamento: 7 settembre 2026.

HyperHealth Connect (HHC) è una piattaforma di interoperabilità sanitaria e semantic data infrastructure progettata per installazioni multi-azienda, multi-facility e multi-site. La documentazione in `docs/` costituisce la baseline completa di progettazione per prodotto, architettura, standard, dati, API, connector, sicurezza, esercizio, sviluppo e quality engineering. Guida implementazione e qualification; ogni release applica le decisioni tramite versioni, matrici di compatibilità ed evidenze verificabili. Le decisioni strutturali evolvono mediante il processo ADR e restano soggette alla validazione tecnica, clinica, di sicurezza, privacy e normativa applicabile.

Consultare [la mappa documentale](docs/README.md) per l'ordine di lettura e le responsabilità.

La [Fase 0 — Engineering Foundation](docs/roadmap/phase-0-qualification.md) è qualificata. Il repository include build multi-modulo, controlli security-first, CI/supply chain, ambienti di riferimento e assurance; la Fase 1 resta un Technical MVP non autorizzato alla produzione clinica.
